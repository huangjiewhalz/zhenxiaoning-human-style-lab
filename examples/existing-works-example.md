# Existing Works Example

## 用户输入

```text
下面是我最近 5 篇文章/帖子。我想把它们沉淀成个人风格 Skill。
用途：公众号文章、小红书标题、视频脚本。
反感：AI 味、鸡汤、太多排比、标题党。
视觉：想要一个固定主体，像一个认真整理线索的小角色，但不要可爱。
```

## 期望处理

模式：已有作品模式 + 视觉主体模式。

应生成：

- 作品证据地图。
- `style-dna.md`：每个判断标明来自哪些样本。
- `anti-style.md`：把“AI 味”拆成具体禁用词、句式、结构。
- `content-patterns.md`：公众号、小红书、视频脚本分别写平台变体。
- `ip-subject.md`：定义原创主体，例如“线团人”，包含动作库和禁忌。
- `composition-patterns.md`：定义线团人如何解线、拉路径、剪断废话，而不是站在角落。
- `examples/on-brand.md` 和 `examples/off-brand.md`：至少各 1 个对照。

## 质量标准

- 不把 5 篇文章混成平均值，要找反复出现的稳定模式。
- 不把用户某一篇里的临时情绪当成永久人格。
- 视觉主体要承担动作，例如解线、拉路径、剪断废话，而不是站在角落。
