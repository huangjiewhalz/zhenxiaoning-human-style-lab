# Off Brand Example

## 任务

识别一段不适合本 Skill 的输出，说明为什么需要退回重写。

## 失败输出片段

```markdown
本 Skill 通过智能化全链路赋能，重塑创作者内容生产闭环，帮助用户快速打造极具高级感的个人 IP 体系，实现从认知到转化的效率跃迁。
```

## 失败原因

- 使用“赋能、重塑、闭环、高级感、效率跃迁”等默认 AI 词。
- 只有宣传语，没有用户证据。
- 没有说明输入、输出和可复用资产。
- 没有体现用户自己的表达方式。
- 容易变成通用 Skill Creator 或营销文案工具。

## 修复方向

- 删除宏大词和营销词。
- 回到具体痛点：AI 每次从零猜，不像用户。
- 说明具体资产：`style-dna.md`、`anti-style.md`、`content-patterns.md`、`qa-checklist.md`。
- 如果需要配图，先判断密度和载体，不直接画满屏卡片。
