# Blank Start Example

## 用户输入

```text
我还没有稳定作品。主要想做 AI 工具和一人公司相关内容。
我讨厌营销号、夸张标题、AI 总结腔。
我希望文字直接一点，有判断，但不要装。
视觉上想要白底手绘解释图，可以有一个小主体，但不要用别人的 IP。
```

## 期望处理

模式：空白起步 + 反风格起步 + 视觉主体模式。

应生成：

- 1-2 个写作风格种子，例如“专业顾问型 + 克制纪实型”。
- 一个原创视觉主体草案，例如“红章操作员”或“线团人”。
- `anti-style.md` 先行，明确禁用营销词、总结腔、夸张标题。
- `visual-style-seed.md` 说明白底、手绘、留白、少量批注、原创主体参与核心动作。
- `composition-patterns.md` 说明第一批只用输入到输出、前后对比、反风格拦截三种结构。
- 明确声明：这是候选风格，不是用户真实风格，需要后续作品校准。

## 不该做

- 不要说已经提炼出用户个人风格。
- 不要复刻任何现成角色。
- 不要给 10 个风格菜单让用户选到迷路。
