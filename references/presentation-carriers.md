# Presentation Carriers

用于避免视觉输出总是回到纸、笔、卡片和文件夹。先根据内容选择“呈现载体”，再选择布局和密度。

呈现载体不是画风。画风可以仍然是铅笔、蜡笔、红笔或手绘线稿；载体决定信息被放在哪里、角色在什么场景里完成动作。

## 选择原则

1. 先看内容材料：评论、网页、按钮、日历、数据、对话、产品功能、证据、角色、路线、复盘。
2. 再选载体家族，不要默认选纸面文具。
3. 同一系列里，相邻两张不能使用同一载体家族。
4. 纸张、卡片、便签、文件夹只是一类基础载体；连续 3 张以内最多用 1-2 张。
5. 如果用户上传了真实截图、网页、产品或角色，只抽象成局部物件，不临摹完整界面或官方标志。
6. 轻配图优先使用载体局部，不画完整场景；新颖载体不能变成“大背景 + 纸片信息”。

## 局部载体规则

当密度是轻配图，载体只取一个最能表达动作的局部物件。画面应该像“一个小道具正在完成一个动作”，不是完整空间。

- 收音调频：只画一个旋钮、半截天线或一段波形，不画完整电台/雷达室。
- 裁缝试衣：只画布样、针线、量尺或一个补丁，不画完整试衣间。
- 暗房显影：只画显影盘、一张照片或一个夹子，不画完整暗房。
- 小店货架：只画一个小格口、一个价签或一个篮子，不画完整店铺。
- 地铁换乘：只画一个换乘点、站牌或短线路，不画完整地铁图。
- 微型街区：只画一个门牌、窗口或路口局部，不画整片城市。
- 舞台后台：只画场记板、幕布边角或一个道具架局部，不画发布会现场。

如果局部物件不足以讲清内容，升级到中密度解释图；不要在轻配图里硬塞完整场景。

## 留白和信息量偏好

载体选择后，再根据用户偏好调整尺度：

- 自动：按内容判断，不额外询问。
- 留白多：只保留载体局部，主体群占画布宽度 25%-38%、高度 20%-32%，四周至少 35% 空白安全边。
- 平衡：保留一个局部载体和少量上下文，主体群占画布宽度 35%-50%。
- 内容更丰富：可以展示更多载体上下文，但必须有分区和主阅读路径；如果没有分区，就拆成系列图。

同一个载体可以有不同信息量：例如“收音调频”在留白多模式只画一个旋钮和两段波形，在内容更丰富模式才画频谱、刻度、信号分类和输出结果。

## 基础载体家族

| 家族 | 适合内容 | 可用物件 | 避免 |
| --- | --- | --- | --- |
| 纸面文具 | 文案批改、轻量观点、草稿 | 稿纸、便签、铅笔、红笔、夹板 | 连续多张都用 |
| 时间记录 | 周期、复盘、习惯、长期积累 | 日历、时间轴、打卡格、版本刻度 | 数据密到像仪表盘 |
| 操作面板 | 模式切换、参数、产品功能、判断 | 开关、旋钮、滑杆、按钮、指示灯 | 科幻控制室、真实 UI |
| 路线地图 | 步骤、成长、用户路径、迁移 | 路标、脚印、岔路、地图格、站点 | 直线箭头串卡片 |
| 空间剖面 | 系统内部、模块关系、上下游 | 小房间、抽屉层、柜格、管道、楼层 | 透视复杂到看不懂 |
| 对话现场 | 用户反馈、客服、协作、争议 | 对话气泡、桌边交流、递交材料、窗口柜台 | 吵架感、满屏气泡 |
| 样本图鉴 | 分类、案例库、角色库、收藏 | 标本夹、图鉴格、标签、编号牌 | 整齐网格太死 |
| 实验检测 | A/B、校准、诊断、验证 | 放大镜、测试卡、量杯、温度计、试纸 | 科幻实验室、医疗感 |
| 票据档案 | 证据、授权、合同、记录留痕 | 票据、封条、档案袋、编号章、锁扣 | 官方公文或机构印章 |
| 舞台展示 | 发布、主角介绍、成果亮相 | 小舞台、灯光、幕布、展台、举牌 | 营销海报感 |
| 工具修理 | 排障、修复、去 AI 味、版本调整 | 扳手、胶带、补丁、螺丝、工具盒 | 机械隐喻过重 |
| 生活实物 | 普通人场景、低门槛教程、轻知识 | 杯子、便利贴墙、桌边物件、包、抽屉 | 装饰性摆拍、喧宾夺主 |

## 新颖载体家族

当用户反馈“不够新颖”“还是像普通信息图”“总是纸笔卡片”时，优先从这里选择。新颖载体仍然要服务内容，不要为了新奇加入无关摆件。

| 家族 | 适合内容 | 可用物件 | 避免 |
| --- | --- | --- | --- |
| 微型街区 | 产品生态、用户旅程、多个角色/模块关系 | 街角、店铺招牌、路口、窗口、门牌 | 复杂城市景观、真实品牌店招 |
| 地铁换乘 | 多步骤路径、分支选择、平台迁移 | 线路、站台、换乘点、站名牌、出口 | 官方地铁图风格、直线流程图 |
| 暗房显影 | 从模糊想法到清晰内容、复盘发现、隐藏线索 | 相片、夹子、红光、显影盘、晾线 | 阴暗恐怖感、真实摄影品牌 |
| 收音调频 | 噪声筛选、评论信号、用户反馈、热点判断 | 旋钮、频谱、波形、天线、刻度盘 | 科幻雷达、复杂音频界面 |
| 邮局分拣 | 多渠道消息、评论归类、交付、跨平台发布 | 信箱、邮戳、格口、地址条、包裹 | 流水线式流程、物流广告感 |
| 裁缝试衣 | 风格校准、语气改造、角色变体、内容适配 | 布样、量尺、针线、衣架、试衣镜 | 时装海报、过度可爱换装 |
| 厨房备料 | 低门槛教程、内容准备、素材整理、组合表达 | 砧板、碗碟、调料罐、食谱卡、围裙 | 食物隐喻替代核心逻辑、油腻美食图 |
| 博物馆展柜 | 案例展示、风格资产、知识收藏、历史版本 | 展柜、标签牌、编号灯、玻璃罩、展架 | 高级感过重、官方展览海报 |
| 舞台后台 | 发布前准备、脚本、直播、角色亮相、内容排练 | 幕布、灯光、场记板、道具架、耳返 | 营销发布会、夸张海报 |
| 天气观测 | 趋势判断、风险预警、情绪变化、舆论信号 | 风向标、雨量杯、云图、温度计、预报板 | 灾难感、真实气象 UI |
| 沙盘推演 | 方案比较、产品策略、路线选择、复盘方法论 | 地形沙盘、旗子、等高线、小标杆、观察镜 | 军事化、战争隐喻 |
| 小店货架 | 产品卖点、内容栏目、服务包装、选题陈列 | 货架、价签、收银台、小篮子、陈列牌 | 电商促销感、真实品牌包装 |
| 维修工位 | 修复 AI 味、排查问题、版本迭代、质检 | 螺丝盒、补丁、胶带、台灯、检查表 | 机械过满、像工业图纸 |
| 观测星图 | 长期方向、选题导航、路径规划、个人定位 | 星图、罗盘、望远镜、坐标点、路线线 | 神秘主义、宇宙大片感 |

## 新颖度选择规则

- 普通正文配图：基础载体 70%，新颖载体 30%。新颖载体只选 1 个，不要叠加。
- 系列 3 张：至少 1 张使用新颖载体。
- 系列 5 张：至少 2 张使用新颖载体。
- 用户明确说“不够新颖”：下一轮至少给 3 个新颖载体方案，并推荐 1 个。
- 如果新颖载体让核心动作变模糊，退回基础载体，但必须说明原因。

## 内容到载体

- 评论、追问、用户反馈：对话现场、时间记录、样本图鉴、操作面板。
- 产品功能：操作面板、空间剖面、特写动作、路线地图。
- 教程步骤：路线地图、小漫画分镜、操作面板、时间记录。
- 风格校准：实验检测、工具修理、纸面文具、样本图鉴。
- 复盘方法论：时间记录、样本图鉴、空间剖面、操作面板。
- 证据和合规：票据档案、时间记录、俯视桌面、特写动作。
- 发布和展示：舞台展示、路线地图、对话现场。

## 内容到新颖载体

- 评论和用户反馈：收音调频、邮局分拣、天气观测、微型街区。
- 产品介绍和功能解释：微型街区、地铁换乘、小店货架、操作面板。
- 教程和步骤：地铁换乘、厨房备料、裁缝试衣、舞台后台。
- 风格校准和去 AI 味：裁缝试衣、暗房显影、维修工位、博物馆展柜。
- 复盘和方法论：沙盘推演、天气观测、博物馆展柜、观测星图。
- 证据、授权和留痕：邮局分拣、票据档案、博物馆展柜、暗房显影。
- 发布和展示：舞台后台、小店货架、微型街区、观测星图。

## 系列轮换

生成 3 张以上时，先写载体轮换表：

```markdown
| 序号 | 主题 | 密度 | 布局 | 呈现载体 | 为什么不用纸笔 | 主体动作 |
| --- | --- | --- | --- | --- | --- | --- |
```

轮换规则：

- 3 张至少 3 类载体。
- 5 张至少 4 类载体。
- 10 张至少 6 类载体。
- 如果上一张用了纸面文具，下一张优先用操作面板、路线地图、对话现场、时间记录或空间剖面。
- 如果上一张用了日历/时间轴，下一张不要再用打卡格或周计划，改用样本图鉴、对话现场或控制台。
- 如果上一张用了图鉴/便签墙，下一张不要再用网格或墙面，改用特写、路线、剖面或舞台。
- 如果用户说“不够新颖”，下一张不要只从基础载体里换；优先用暗房显影、收音调频、地铁换乘、微型街区、裁缝试衣、沙盘推演、小店货架或舞台后台。

## Prompt 字段

生成视觉 prompt 时加入：

```text
Presentation carrier:
{纸面文具 / 时间记录 / 操作面板 / 路线地图 / 空间剖面 / 对话现场 / 样本图鉴 / 实验检测 / 票据档案 / 舞台展示 / 工具修理 / 生活实物 / 微型街区 / 地铁换乘 / 暗房显影 / 收音调频 / 邮局分拣 / 裁缝试衣 / 厨房备料 / 博物馆展柜 / 舞台后台 / 天气观测 / 沙盘推演 / 小店货架 / 维修工位 / 观测星图}

Carrier rule:
Use this carrier as the main place where information lives. Do not default to paper cards, sticky notes, folders, or pencils unless the selected carrier is 纸面文具.

Framing scale:
{局部轻描 / 小场景 / 完整场景 / 工作台}. 轻配图默认局部轻描，主体群占画布宽度 30%-45%、高度 25%-40%，四周至少 25% 空白安全边；用户反馈太满时缩到宽度 30%-40%、高度 25%-35%，四周至少 30% 空白安全边。

Whitespace preference:
{自动 / 留白多 / 平衡 / 内容更丰富}. 用户没说时自动判断；用户明确说留白多或内容更丰富时优先执行。
```

## QA

失败信号：

- 同一系列看起来只是换了文字的纸笔图。
- 角色每次都拿笔、圈纸、贴便签。
- 载体说是控制台/地图/对话，但画面主体仍然是几张卡片。
- 为了多样化加入无关摆件，核心动作反而不清楚。
- 所谓新颖载体只是换背景，信息仍然在纸片、卡片和文件夹里。
- 轻配图把新颖载体画成完整房间、完整街区、完整店铺或完整路线，导致画面天然变密。
- 主体群占满中间大部分画布，四周留白不够，画面看起来不精致。
- 新颖载体过度复杂，主体动作和核心意思被淹没。
- 使用真实平台 logo、真实 UI 或第三方品牌视觉。
