# Platform Image Sizes

用于把同一套个人风格资产适配到不同自媒体平台、画面位置和发布场景。不要默认所有配图都是 16:9；先判断平台和用途，再决定画幅、密度、构图尺度和安全区。

平台尺寸会随产品改版变化。这里记录的是当前常用安全预设，生成时仍要优先服从用户指定尺寸、平台后台提示或最新官方规则。

## 使用时机

在这些情况先读取本文件：

- 用户点名平台：小红书、微信公众号、X、Instagram、Threads、抖音/TikTok、视频号、B 站、YouTube、LinkedIn、官网、PPT、Notion。
- 用户说“封面图”“正文配图”“轮播图”“长图”“卡片图”“首图”“分享图”“帖子图”“自媒体尺寸”。
- 用户要求同一内容适配多个平台。
- 用户反馈图片被裁切、字太靠边、发到平台后不好看。

## 先问或推断的字段

```markdown
## Platform Size Card

- 平台：
- 位置：封面 / 正文配图 / 轮播单页 / 长图 / 视频封面 / 分享卡片 / 个人主页图 / 通用
- 目标尺寸：用户指定 / 平台预设 / 待判断
- 目标比例：
- 是否一图多用：是 / 否
- 是否有平台 UI 遮挡：顶部 / 底部 / 左右 / 无 / 待判断
- 是否有平台裁切：中心裁切 / 方形裁切 / 信息流预览裁切 / 无 / 待判断
- 推荐密度：轻配图 / 中密度解释图 / 高密度工作台
- 推荐构图：横向 / 方形 / 竖向 / 超宽 / 长图
- 安全区：
```

信息不足时，用平台默认值，但把尺寸写成“建议尺寸”，不要声称是唯一标准。

## 自动选择逻辑

1. 用户指定尺寸时，使用用户尺寸；如果不适合平台，提醒可能被裁切。
2. 用户只指定平台时，按平台默认场景选尺寸：
   - 小红书：默认 1080 x 1440。
   - 微信公众号：封面默认 900 x 383；正文配图默认 1080 x 608 或 900 x 500。
   - X：默认 1280 x 720；如果是卡片/广告，用 1200 x 628 或 1200 x 1200。
   - Instagram/Facebook Feed：默认 1080 x 1350。
   - 竖屏短视频/Stories：默认 1080 x 1920。
   - PPT/视频封面/论坛展示：默认 16:9。
3. 用户说“全平台通用”时，不直接生成一张万能图，优先输出 3 个版本：
   - 横版：16:9，用于公众号正文、X、PPT、论坛。
   - 竖版：3:4 或 4:5，用于小红书、Instagram、移动端信息流。
   - 方版：1:1，用于分享卡片、头像式封面、社群。
4. 同一组轮播图片必须保持同一比例；不要一张 3:4、一张 1:1、一张 16:9 混用。
5. 如果图里有中文短词、角色脸、奖杯、logo 或关键结论，不要用裁剪适配；必须重构图。

## 构图重排规则

### 超宽图：2.35:1 / 1.91:1

适合公众号头图、X 链接卡片、LinkedIn 链接图。

- 阅读路径横向展开。
- 主体和短词放在中心安全区。
- 左右两侧用于留白、辅助道具、轻批注。
- 不使用竖向长流程、完整工作台或密集卡片墙。
- 公众号头图必须检查中间方形裁切后是否仍能看懂。

### 横图：16:9

适合正文配图、X 信息流、视频封面、PPT。

- 适合中密度解释图。
- 主体可在左、中、右三分区之一，但不能贴边。
- 手写文字保持短，不做大标题排版。
- 可承载 1 个主场景 + 1-2 个信息区。

### 方图：1:1

适合社群、分享图、方形封面、卡片。

- 只讲一个核心动作。
- 主体居中或略偏下。
- 最多 1-3 个短词。
- 不适合复杂流程和多分区工作台。

### 竖图：3:4 / 4:5

适合小红书、Instagram/Facebook Feed、移动端图文。

- 上：问题、钩子或关键道具。
- 中：主体动作。
- 下：结果、结论或下一步。
- 适合轻配图或中密度；高密度要分层，不要堆满。
- 文字和角色脸避开顶部、底部和左右边缘。

### 全屏竖图：9:16

适合短视频封面、Stories、Reels、视频号、抖音/TikTok。

- 只放一个强主视觉，不放完整方法论。
- 顶部留 12%-15% 安全区，底部留 18%-25% 安全区。
- 关键文字放在中间 60% 高度范围内。
- 角色主体可占画面高度 35%-55%，但四周必须有呼吸空间。

### 长图

适合公众号长图、知识清单、教程复盘。

- 不是把一张高密度工作台无限拉长。
- 每屏只讲一个节点，分段之间有明显留白。
- 顶部先给总标题或总图，后面按卡片段落展开。
- 中文文字仍要短；长解释放到正文，不写进图里。

## 多平台适配策略

同一内容要发多个平台时，优先做“同源多版”，不要硬裁剪一张图。

### 推荐三件套

| 版本 | 尺寸 | 用途 | 适配重点 |
| --- | --- | --- | --- |
| 横版主图 | 1600 x 900 / 1920 x 1080 | 公众号正文、X、PPT、论坛 | 清楚解释一个机制 |
| 竖版信息流 | 1080 x 1440 / 1080 x 1350 | 小红书、Instagram、移动端 | 上中下结构，留足安全区 |
| 方版卡片 | 1080 x 1080 | 分享卡片、社群、头像式封面 | 一个动作 + 一个结论 |

### 生成顺序

1. 先确定核心意思和角色动作。
2. 生成横版或竖版母版。
3. 再按平台重排，不直接裁剪。
4. 每个版本重新列 `Exact Chinese text allowed`。
5. 逐张检查文字、角色脸、奖杯、核心道具是否在安全区。

## 输出格式

生成布局规划时加入：

```markdown
## 平台尺寸计划

| 序号 | 平台/位置 | 推荐尺寸 | 比例 | 密度 | 构图重排 | 安全区 | 是否可由母版裁切 |
| --- | --- | --- | --- | --- | --- | --- | --- |
```

单张 prompt 必须包含：

```text
Output size / aspect ratio:
{平台尺寸，例如 1080x1440, 3:4}

Platform placement:
{小红书图文封面 / 微信公众号头图 / X 信息流 / 公众号正文配图 / 通用 16:9 ...}

Safe area:
{关键文字、角色脸、核心道具必须放在哪个区域；哪些边缘不能放重要内容}

Recomposition rule:
This image is composed natively for this platform size. Do not simply crop a 16:9 layout into this ratio.
```

## QA

失败信号：

- 把 16:9 横图直接裁成小红书竖图，导致角色、文字或核心道具被切掉。
- 公众号头图没有中心方形安全区，分享时看不懂。
- 小红书轮播多张图比例不一致。
- 9:16 图把重要文字放在顶部或底部 UI 遮挡区。
- 方图里放了太多流程和小字。
- 同一内容多平台只做裁剪，没有重排构图。
- 只写像素，不说明比例、用途、安全区和是否重构图。
