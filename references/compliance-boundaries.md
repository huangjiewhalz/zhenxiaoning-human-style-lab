# Compliance Boundaries

## 允许

- 用户自己的文章、笔记、视频脚本、标题、图片说明、设计说明、产品文案。
- 用户明确授权的品牌资料。
- 抽象风格方向，例如“更短句、更克制、更少营销感、更像产品复盘”。
- 原创 IP 主体，例如用户自己定义的纸片人、印章、线团、盒子、墨块。

## 不允许

- 复刻名人、在世创作者、博主、画师、设计师、同事、朋友或任何未经授权个人的可识别风格。
- 伪装成某个人发言。
- 抓取第三方内容制作“风格分身”。
- 用风格资产绕过平台检测、误导读者来源或冒充真人授权。
- 换一个名字但保留第三方 IP 的外形、动作、构图和识别点。

## 替代写法

当用户要求模仿第三方时，改成抽象约束：

```text
我不能复刻某个在世创作者或可识别个人风格。
可以把需求改成抽象方向：短句、克制、少形容词、先判断后解释、白底手绘、少量批注、固定原创主体参与核心动作。
```

## 样本处理

- 不要把用户提供的全部原文长期塞进生成的 Skill，除非用户明确要求。
- 优先提炼规则、短引用和证据摘要。
- 涉及隐私、客户信息、内部数据时，先脱敏再写入资产包。

## 视觉边界

白底手绘解释图是抽象视觉方向，不等于某个作者的可识别风格。

生成视觉资产时必须：

- 换成用户原创主体。
- 换成当前内容的新隐喻。
- 不复用第三方案例构图。
- 不使用第三方角色名。

## 品牌资料

如果用户提供公司或团队资料，默认只做“授权品牌 voice guide”。不要把它写成某个具体员工的个人风格，除非员工本人授权且用户明确说明。
