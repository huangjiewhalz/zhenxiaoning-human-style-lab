# Handdrawn Style Seeds

用于给个人风格资产包选择“手绘工具感”。这些种子都服务同一个目标：降低默认 AI 精修感，让画面更像人用真实材料画出来的。

## 使用规则

- 先选手绘工具风格，再选原创 IP 主体。
- 一次只推荐 1-2 种手绘风格。
- 每种风格都要写清适合、不适合、颜色、线条、失败信号。
- 不模仿具体画师、博主、品牌或可识别作品。
- 如果用户没有偏好，默认从“白底彩铅草稿风”起步；需要更克制、更清爽、更像思考草稿时选“铅笔草图风”；需要诊断、批改或去 AI 味修复时选“红笔批改风”；用户明确想要“虚实结合、实物拼贴、真实工作台、照片物件 + 手绘角色”时，才选“实物拼贴手绘风”；用户明确想要“抽象镇小宁、随手画、涂鸦、乱线彩铅、像真人但不是肖像、更艺术的镇小宁”时，才选“抽象镇小宁涂鸦风”。
- 点名镇小宁 IP 的多风格对比里，用户说“抽象涂鸦”就按“抽象镇小宁涂鸦风”处理；不要生成普通抽象蓝色角色。
- 本文件里的线团人、红章操作员、空心方盒等主体例子只在用户没有上传、点名或设定任何角色时可用。用户点名具体角色但缺少参考图时，不得用这些主体顶替；先要求角色图或改为无角色配图规划。

## 当前正式风格

维护三种核心手绘风格和两种可选实验风格，避免变成风格大全：

- **白底彩铅草稿风**：默认主风格，适合个人 IP、正文配图、轻知识、情绪感和更有新鲜感的内容解释。它对应用户指定的参考图质感：白底、黑灰铅笔打稿线、彩铅颗粒填色、手写云朵批注和松弛小装饰。
- **铅笔草图风**：克制变体，适合更清爽的产品解释、轻知识、教程和需要低干扰的正文配图。
- **红笔批改风**：诊断专用，适合去 AI 味、反风格清单、标题修改和文案 QA。
- **实物拼贴手绘风**：可选展示风格，适合 Skill 自我介绍、工作流复盘、AI 实验日志和产品功能解释。用真实物件搭小现场，再让手绘角色参与动作。它不是默认主风格，也不用于固定 IP 最终一致性成稿。
- **抽象镇小宁涂鸦风**：可选 IP 变体风格，适合把镇小宁画成更抽象、更随手、更艺术、更有真人情绪感的角色小样或内容配图。它不是新主体，也不是普通蓝色涂鸦角色；必须保留镇小宁或用户固定主体的识别点。若存在抽象镇小宁唯一母版，必须从这张母版延展，不要每次重新发明一套抽象画法。
- 抽象镇小宁默认只做“状态图 / 情绪图 / 文章边角气氛图”，不做复杂观点解释图。凡是需要表达多步逻辑链、商业机制、教程步骤、产品功能或方法论总结的内容，默认回到白底彩铅或虚实结合。

暂不默认加入 Riso、木刻、纸艺等风格。它们可以作为未来实验方向，但不进入自动选择，除非用户明确要求“更封面感”“更强视觉冲击”或“想试实验风格”。

## 铅笔草图风

### 一句话

像创作者在白纸上用铅笔认真推演一个想法：线条松、轻重有变化，结构清楚但不精修，像真实思考留下的草稿。

### 适合

- 用户明确要求更克制、更清爽、更像思考草稿的正文配图。
- 产品解释、功能说明、轻知识、教程步骤。
- 个人风格资产、写作结构、内容工作流、AI 味诊断前的轻量解释。
- 用户希望“别太花、别太幼稚、信息更干净”的场景。
- 需要留白多、主体小、局部轻描的配图。

### 不适合

- 需要强情绪、强封面视觉冲击的内容。
- 需要彩色记忆点或更温暖个人 IP 氛围的内容。
- 已经明确要红笔批改、错误诊断或 before/after 修改痕迹的任务。
- 复杂数据图、正式架构图和需要精确 UI 复刻的内容。

### 视觉材料

- 统一白纸底；可以是纯白，也可以是很浅的纸白 / 浅纸色，但同一组图必须一致。允许线条和局部阴影有铅笔质感，不把底色做成明显奶油黄、旧纸或暗角。
- 铅笔、自动铅笔、灰黑草图线。
- 轻微重复描边、擦除痕、淡淡阴影。
- 少量红、蓝或橙色手写批注。
- 局部道具和主体动作，不画满完整场景。

### 颜色规则

- 主线：灰黑、蓝黑或深灰，不要纯黑硬边。
- 填色：默认少量或不填色；如果需要角色识别，可保留 1-2 个低饱和识别色。
- 批注：红、蓝、橙最多 1-2 种，像小手写注，不做大标题。
- 文字：只使用 prompt 里列出的短词，不自动新增标题、解释句或段落。短词默认由 Agent 从目标文案里自动提取，不要求用户手动列词；默认把这些短词直接画进图里，像小手写批注、云朵短词、小标签或纸角字迹；不要把气泡、标签和卡片全部留空。
- 背景：保持统一白纸底，不加明显奶油黄/旧纸底、渐变、光效和大面积色块。

### 线条规则

- 线条允许断裂、轻微抖动、重复描边。
- 阴影用稀疏斜线、轻擦痕或淡灰涂抹。
- 箭头、框线、标签都要像临时手写，不要像矢量组件。
- 轻配图主体群缩小，保留明显外圈留白。
- 不追求完美透视和精密结构，优先保留“正在想”的痕迹。

### 适合的主体

- 空心方盒：适合产品、模块、工具机制。
- 纸片工人：适合写作、文档、风格资产整理。
- 线团人：适合混乱线索、流程和关系。
- 用户上传角色：适合保留角色识别点，但要降低光滑感和商业插画感。

### 禁止画法

- 不要做成商业矢量插画。
- 不要做成漂亮 UI mockup 或 PPT 架构图。
- 不要变成儿童简笔画。
- 不要加 3D 光影、玻璃感、霓虹、复杂渐变。
- 不要把铅笔风理解成“黑白草稿低完成度”；结构仍然要清楚。
- 不要模仿任何具体画师、博主、品牌或可识别作品。

### 示例 prompt

```text
Create a single pencil sketch style illustration for a Chinese article, composed natively for the target platform size and aspect ratio. If no platform or size is specified, use a horizontal 16:9 composition.
Use a clean white paper background, loose gray-black pencil lines, light sketch shadows, slight repeated strokes, and a few small handwritten Chinese notes in red or blue. The image should feel like a real thinking sketch on paper, not a polished vector infographic, UI screen, poster, or children's drawing.

Original subject:
空心方盒, a small original hollow box character with simple eyes and thin pencil-like legs, calm and practical, not cute.

Topic:
让 AI 记住我的风格，而不是每次从零猜。

Meaning:
The user needs reusable style assets, not a longer prompt every time.

Scene:
Use a light local close-up, not a full scene. In the center, the hollow box character gently places one small note labeled "语气" into a simple open drawer. Beside it are two tiny pencil notes labeled "结构" and "禁用词". A soft arrow points to a small output slip labeled "像我一点".

Short Chinese notes:
语气 / 结构 / 禁用词 / 像我一点

Exact Chinese text allowed:
语气 / 结构 / 禁用词 / 像我一点

Framing:
Keep the subject/object cluster small, around 35% of canvas width, with large blank white margins on all sides. No full desk, no full room, no big title.

Color:
Use gray-black pencil lines, very light gray shading, and only tiny red or blue handwritten notes.

Avoid:
polished vector art, 3D rendering, glossy gradients, dense arrows, full scene, slide layout, commercial mascot style, copied examples, third-party IP, recognizable living-artist style, and large title text.
```

### QA 失败信号

- 看起来像未完成草稿，核心意思不清楚。
- 线条太干净、边缘太锐，像矢量图。
- 主体或道具太大，四周没有呼吸感。
- 批注变成大标题或信息图标签。
- 为了“铅笔感”变成全黑白，丢掉角色识别点。
- 只有道具，没有主体参与核心动作。

## 白底彩铅草稿风

### 一句话

像创作者在白纸上先用铅笔打线稿，再用彩铅一层层涂出角色和道具：轮廓有草稿感，颜色有颗粒和斜向笔触，旁边有手写云朵批注、下划线、小星星和随手箭头。

### 适合

- 个人 IP 和原创主体。
- 创作者状态、成长、情绪、轻知识。
- “AI 不像我”“从混乱到清楚”“把风格沉淀成资产”这类有一点人的手感的主题。
- 需要比黑白线稿更温暖、更有新鲜感的正文配图。
- Skill 默认风格；用户没有偏好时优先选择它，再根据内容调整密度和留白。
- 需要角色显得有生命力，但仍像真实手画出来，而不是 3D 吉祥物或商业插画。

### 不适合

- 严肃 B2B 架构图。
- 复杂系统图。
- 需要精确可读的小字信息图。
- 法律、医疗、金融等高严肃度内容。
- 用户明确要求极简、克制、低颜色干扰的草稿图。

### 视觉材料

- 统一白纸底，不加明显奶油黄、旧纸底或背景色块。
- 铅笔或深灰彩铅结构线，允许重复描边和轻微歪线。
- 彩铅斜向填色、短线叠色和颗粒，色块不均匀，允许露白。
- 角色和重要道具可以有较完整填色，但必须保留明显彩铅笔触。
- 少量手写中文短词、云朵批注、蓝色下划线、小星星、小爱心和随手箭头。
- 允许局部轻微高光，但不能变成光滑 3D 或喷枪效果。

### 颜色规则

- 主线：深灰、蓝黑、深棕或彩铅黑，不要纯数字黑的硬边。
- 主色：选 2-4 个彩铅色，常用蓝、黄、红、浅紫、浅橙。
- 角色识别色要保留，但不要做成光滑渐变或 3D 明暗。
- 背景保持干净，不要做满版彩色。
- 色块不追求涂满，允许露白、交叉笔触、斜向涂痕和轻微涂出边界。

### 线条规则

- 线条可以歪、抖、重复描边，但关键轮廓要清楚。
- 形状可以不完全闭合，局部有铅笔打稿痕迹。
- 填色以短线、斜线、轻擦痕、反复叠色为主，避免大面积平涂。
- 箭头、云朵框、星星、下划线都要像手画的，不能像矢量装饰。
- 不能变成矢量图标、商业插画、儿童贴纸或低龄涂鸦。

### 适合的主体

- 纸片工人：适合文档、风格归档。
- 线团人：适合从混乱样本里抽线索。
- 空心方盒：适合风格资产包和模块化表达。
- 用户上传角色或本机私有默认角色：保留识别点，再转换成彩铅颗粒手绘质感。

### 禁止画法

- 不要画成幼儿园儿童画、儿童贴纸或低幼贺卡。
- 不要满屏彩色，保持白底和留白。
- 不要可爱吉祥物化到失去原角色识别点。
- 不要 3D、渐变、光影、精修插画、商业 mascot 海报。
- 不要纯蜡笔粗块面，也不要纯黑白铅笔草稿；必须有彩铅颗粒、铅笔打稿线和手绘填色。
- 不要模仿任何具体画师。

### 示例 prompt

```text
Create a single white-background colored-pencil sketch illustration for a Chinese article, composed natively for the target platform size and aspect ratio. If no platform or size is specified, use a horizontal 16:9 composition.
Use a clean white paper background. Draw with loose gray-black pencil construction lines, colored-pencil outlines, visible grainy pencil strokes, diagonal colored-pencil hatching, repeated hand pressure marks, and imperfect hand-drawn shapes. Add a few handwritten cloud notes, blue underline strokes, small stars or hearts, and casual arrows. The result should match a warm colored-pencil sketch made by hand, not a children's crayon drawing, not a polished vector illustration, and not a 3D mascot render.

Original subject:
User's locked IP subject or original subject, converted into white-background colored-pencil sketch texture while preserving all identity points. If no user subject exists, use a small original subject seed, serious and not childish.

Topic:
让 AI 记住我的风格，而不是每次从零猜。

Meaning:
The user needs reusable style assets, not a longer prompt every time.

Scene:
Use a light local close-up, not a full room. The subject actively handles the core metaphor: pulling useful style clues out of a messy little pile, then placing them into three hand-drawn containers labeled "语气", "结构", "禁用词". Add a few hand-drawn cloud notes, tiny stars, small arrows, and uneven colored-pencil shading. Keep the text sparse.

Short Chinese notes:
旧作品 / 语气 / 结构 / 禁用词 / 像我一点 / 待校准

Exact Chinese text allowed:
旧作品 / 语气 / 结构 / 禁用词 / 像我一点 / 待校准

Color:
Use a small colored-pencil palette: blue, yellow, red, light purple, orange, and dark gray. Leave plenty of white space. Color blocks should show diagonal pencil hatching, grain, repeated pressure marks, and small areas of white paper showing through.

Avoid:
polished vector art, 3D rendering, glossy gradients, airbrushed lighting, dense arrows, slide layout, commercial mascot style, children's crayon poster, wax-crayon blocky texture, copied examples, third-party IP, and corner titles.
```

### QA 失败信号

- 看起来像 AI 精修插画，而不是彩铅手绘。
- 太儿童画，读者会觉得低幼。
- 色彩太满，正文配图变成海报。
- 主体只是可爱装饰，没有完成核心动作。
- 中文标签太多或太小。
- 只有纯蜡笔粗糙块面，没有铅笔结构线和彩铅斜向填色。

## 抽象镇小宁涂鸦风

### 一句话

像把镇小宁画在草稿本边角：重复乱线、彩铅涂痕、比例幼拙，第一眼更抽象、更有人味和艺术感，但仍能认出这是镇小宁的一个抽象变体。

### 适合

- 用户明确说“这个就是镇小宁，只是更抽象”“更随手画”“更艺术”“像真人但不是肖像”“涂鸦版镇小宁”。
- 角色小样、头像方向探索、表情实验、封面局部视觉、社媒轻配图。
- 能用一个状态词、一个情绪或一个瞬间动作概括的内容，例如卡住、冒出来、过载、跑偏、松口气、绷住、被缠住、被点亮。
- 文章中的情绪插针、小节转场、边角小插图和“读者此刻的状态”，例如“粉丝少也能开始”“脑子打结但灵感冒出来了”。
- 需要更强手作感、情绪感、艺术感，而不是稳定商业 IP 成稿的场景。
- 本机方向预览：如果尚未固定唯一母版，当前生图工具不能接参考图时，可先做“抽象镇小宁方向预览”，但仍要标注不是最终 IP 一致性成稿；一旦已有唯一母版，优先使用或展示母版，不文本重画。
- 已经绑定抽象镇小宁唯一母版时，后续抽象风必须固定使用这张母版，不从文字描述随机重画，也不从多张抽象图里随机选择。
- 已有唯一母版且当前工具不能接入图像参考时，默认不要文本生图重画抽象镇小宁；多风格对比、风格选择或小图测试里，直接展示/引用这张母版作为抽象风格小图。只有用户明确接受“无母版输入的松散方向预览”时，才允许文本生图尝试。

### 不适合

- 需要严格统一的固定 IP 最终成稿。
- 产品说明、教程、方法论工作台等需要信息清晰优先的图。
- 需要读者看懂多步关系的观点图、教程图、机制图和商业路径图，例如“AI 是普通人最后一次机会”“穿搭博主有哪些变现方式”“三步建立个人 IP”。
- 抽象变形需要配口头解释才能看懂的图；如果读者第一眼只能看到“镇小宁变形了”，但读不出状态，判定不适合。
- 需要严肃、克制、可信的 B2B 或专业内容。
- 用户没有点名镇小宁、没有本机私有绑定，也没有上传/指定自己的固定角色时。

### 视觉材料

- 统一白纸底是硬约束：抽象图必须跟随同组背景系统，可以是纯白，也可以是很浅的纸白 / 浅纸色，但不能单独漂成明显奶油黄、旧纸色、暗角或大面积粗纸纹。抽象的粗糙感主要来自角色、道具、线条和涂色，不靠换底色制造差异。
- 彩铅、蜡笔感彩铅、圆珠笔或软铅笔的重复乱线。
- 涂色允许出边、露白、颜色叠错、边界不完全闭合。
- 镇小宁识别点保留为抽象符号：蓝色圆润主体、白色肚皮、红色圆鼻子、大白眼黑瞳、黄色眉毛、头顶两根黄色长耳/触角、两侧尖耳或蓬松侧边轮廓。
- 场景、道具和信息载体也要使用同一套抽象手绘材料：便签、线缆、纸堆、按钮、桌角、工具和云朵批注都应像草稿本里的乱线彩铅小符号，而不是照片物件、写实桌面、摄影棚道具或干净 UI。
- 可以有更像真人的情绪：发呆、认真、困惑、倔强、害羞、疲惫、好奇；但不能画成人类脸、真人头像、自拍感、职业照或半身像。

### 抽象优先级

- 抽象必须先作用于镇小宁本体，而不是先作用于背景、道具或“AI 味”涂鸦云。
- 角色本体要显著接近唯一母版：全身蓝色乱线密度、幼拙身体比例、略歪脸型、不对称大眼、红鼻位置、黄色长耳形状、白肚皮比例、侧耳/侧刺轮廓和粗糙涂色都要可见。
- 如果画面只是普通干净卡通镇小宁，旁边多了乱线背景、涂鸦云、抽象道具或手写批注，判定为抽象失败。
- 抽象图的第一眼差异应该来自“镇小宁本体变成母版那种随手画小样”，不是来自旁边的解释性元素。

### 抽象变形生成规则

抽象变形不是固定动作库，也不是普通镇小宁和抽象道具互动，更不是从“缩成一团 / 耳朵变天线 / 鼻子变警报”等少数模板里抽取。变形主语必须是镇小宁本体：耳朵、鼻子、肚皮、眼睛、身体轮廓、手脚、侧耳、颜色线团或影子在变。外部纸缝、便签、线缆、标签只能做压力源或触发点，不能成为主视觉。每次都必须从当前内容重新推导：

1. **状态词**：这次只表达一个状态，例如卡住、冒出、过载、跑偏、松口气、快被模板化。
2. **主题对立轴**：先写清这张图里的两股力量，例如人味 vs 模板、混乱 vs 清楚、试探 vs 确定、自由生长 vs 被校直。
3. **形状语义**：把对立轴翻译成形状变化，例如圆/歪/软/弹回代表人味，方/直/齐/硬代表模板；散乱线代表未成型，聚拢小窗口代表被看见。
4. **主受力线**：这个状态像什么物理变化，例如被压住、被拉长、被缠住、被撑开、被挤扁、被点亮、被打结、被剪开、被吹散、被吸进去、被托起来、被拽回来。
5. **身体部位**：选择镇小宁的耳朵、鼻子、肚皮、眼睛、身体轮廓、手脚、侧耳、颜色线团或影子承担这个变化。
6. **变形结果**：让身体部位和动作共同表达状态，而不是让镇小宁站着、旁边放一个抽象符号。
7. **3 秒读图校验**：去掉外部道具和解释文字后，只看镇小宁本体的形状变化，是否还能感到这个状态；不能则重写形状语义。

变形主视觉必须是镇小宁自身的个体变形。压力源不是必选项；能用身体状态表达时，不要额外加入外部压力源。若使用外部纸缝、便签、线缆或标签，它们只能是很小的触发点或参照物，不能和镇小宁共同构成平级主体，更不能成为最大的视觉块。变形可以明显，但不能铺满画面。正文轻配图、转场状态图和方向预览里，抽象镇小宁本体和少量触发点/短词组成的画面关系仍应保持小局部，默认不超过画布宽度约 30%-42%、高度约 25%-36%，四周保留至少 30% 白纸留白；用户反馈太满时缩到宽度 25%-38%、高度 20%-32%。只有角色小样、头像或近景风格实验才允许放大变形主体。

形状语义比外部道具更重要。不要只写“被压住 / 被拉长 / 被缠住”；必须说明为什么这次选择的圆/方、软/硬、散/齐、弯/直、开/合能代表当前主题。例：表达“人味不要被模板化”时，不要画巨大模板压镇小宁；优先让镇小宁身体一侧被校直成歪方格，另一侧仍保持圆润乱线并弹回，白肚皮保留不规则小窗口，红鼻子像自我从方格边缘冒出来。

身体部位不能默认都选肚皮 / 白肚子。肚皮适合表达内在核心、承载、消化、自我中心或被看见；耳朵适合表达方向、外界声音、被拉偏或重新竖起；红鼻子适合表达锚点、堵点、启动点或注意力；眼睛适合表达失焦、聚焦、犹豫或醒过来；身体轮廓适合表达边界、压力、松弛、散开或收拢；手脚适合表达抓住、停住、够不到、接近或行动卡住；影子和颜色线团适合表达漂移、分身、残留情绪或余波。连续测试或同一组抽象图里，不得多张都用肚皮作为主变形；如果上一张主变形是肚皮，下一张优先换耳朵、眼睛、身体轮廓、手脚、影子或红鼻子。

语义容易误读的动词要先消歧。“接回 / 恢复 / 重新开始 / 找回来”不等于接断线、接线束、修电线或缝合裂缝，除非内容本身就是电线、缝合或维修。默认把它画成状态恢复：重心回中、身体轮廓从散开收拢、眼神重新聚焦、耳朵从倒伏回弹、脚重新踩住纸面、影子回到身体下面。否则读者会以为主题是修复一根断线，而不是镇小宁把自己接回来。

#### 发散候选池

不要等生成失败后再补一条禁令。每次做抽象变形前，先发散 3-5 个候选变形，再选最贴主题的一张。候选必须来自不同身体系统，不能只是同一个肚皮窗口换说法：

1. **轮廓 / 重心候选**：身体整体变圆、变低、变歪、变方、散开、收拢、漏气、弹回。
2. **耳朵 / 触角候选**：竖起、倒伏、被拉偏、弯回、变方向标、变感应器、互相打结。
3. **眼睛 / 鼻子候选**：失焦、聚焦、错位、盯住、鼻子变锚点、堵点、启动点或注意力钉。
4. **手脚 / 姿态候选**：抓住、停住、够不到、往回拽、踩住、缩起、探出去。
5. **影子 / 颜色线团候选**：影子错位、影子归位、颜色拖影、余波、分身、残留噪声。
6. **局部材料候选**：身体局部揉皱、折叠、撕开、起泡、结晶、漏气、静电炸开。

候选选择用 4 个问题打分：是否 3 秒内贴主题；是否保留镇小宁识别点；是否和上一张身体系统不同；是否不依赖外部道具也能读。选中的候选才进入生图 prompt；未选候选不需要画出来。

同一个状态也要根据上下文产生不同变形，例如“卡住”可以是身体被蓝色线团缠住、耳朵夹在两个方向之间、白肚皮被格子压住、红鼻子堵在细线口、手脚被便签贴住。不得连续复用同一套变形结构。

变形种类要轮换，不要只在“压扁 / 拉长 / 缠住”里打转。每次至少从下面选择 2 个轴组合：

- **受力方向**：上压、下坠、侧推、反向拉扯、向内吸、向外撑、绕圈卷、斜向滑走。
- **材料状态**：揉皱、折叠、撕开、融化、结晶、起泡、漏气、弹回、静电炸开、影子错位。
- **身体部位**：耳朵变方向标、红鼻子变堵点或启动点、白肚皮变小窗口、眼睛变失焦/聚焦、侧耳变毛边、手脚变夹子/钩子/短线。
- **运动轨迹**：被拖出、钻进去、弹出来、悬停、沉下去、绕远路、卡在边缘、从纸缝里露出一点。
- **情绪姿态**：硬撑、偷看、憋住、松掉、愣住、探头、犹豫、突然醒来。

同一组图里连续 3 张抽象镇小宁不得重复同一种“受力方向 + 身体部位”组合；如果重复，先换身体部位或材料状态，不要只换道具和短词。

### 唯一母版规则

- 抽象镇小宁一旦有唯一母版，就按“母版驱动”执行，不再只按文字 prompt 重新生成。
- 生成前固定使用唯一母版；不要再做多图候选选择，也不要把其它抽象图当作同级候选。
- 能接入参考图或图像编辑时，必须把唯一母版作为实际图像输入、identity source 或 style source。
- 如果工具只能文本生图且没有接入唯一母版，不得声称已经复用了唯一母版；已有唯一母版时，默认展示/引用母版图，不生成新的抽象镇小宁角色。
- 如果是多风格对比或风格选择测试，且工具不能把唯一母版作为图像输入，不要新生成抽象镇小宁变体；直接使用唯一母版本身作为抽象风格展示图，避免把普通蓝色卡通误交付为抽象镇小宁。
- 唯一母版用于锁定抽象画法的稳定边界：蓝色乱线密度、红鼻子位置、黄色长耳形状、白肚皮比例、大眼睛、侧耳/侧刺轮廓和整体脸型。母版不锁定输出背景色；实际成图必须跟随同组统一白纸底。
- 允许基于唯一母版做动作、表情、尺度和道具变化；不允许生成母版之外的新物种、新脸型、新耳朵结构或新的普通蓝色吉祥物。
- 如果用户新增抽象参考图，只有在明确替换母版时才更新本机私有绑定文件；不要把私有参考图提交到公开仓库。

### 颜色规则

- 主色仍以镇小宁识别色为核心：蓝、黄、红、白、少量紫或粉。
- 颜色可以更高饱和、更直接，像手边几支彩铅随手涂出来。
- 蓝色不能变成普通蓝色吉祥物的大面积平涂；必须有乱线、露白、涂痕和识别部件。
- 背景必须保持同组统一白纸底，不做明显奶油黄纸底、旧纸纹、渐变、喷枪、光效、暗角或商业海报底。

### 线条规则

- 允许重复描线、乱线、来回涂、边缘毛躁和比例不稳定。
- 眼睛、鼻子、耳朵/触角、肚皮轮廓必须清楚，不能被乱线吞掉。
- 不追求干净轮廓，但要保留“这是镇小宁”的第一眼识别。
- 如果用于正文配图，仍按中等小角色尺度，但抽象镇小宁要比普通固定角色更重视可识别性。自动尺度按状态图任务判定：角色小样/头像/表情实验 32%-45%；轻配图、自我介绍展示、方向预览和转场状态图 26%-34%；少量道具的状态小场景 22%-30%。抽象不进入高密度工作台、复杂观点解释、教程步骤或商业机制；遇到这类任务先改用白底彩铅或虚实结合。prompt 中必须同时写可读性和相对尺度，例如“红鼻子、白肚皮、黄耳和大眼清楚；比主道具略小或相近，不是远处小贴纸”。如果母版识别点不清楚，先减少短词和道具、拆系列或放大角色，不接受普通蓝色吉祥物结果。
- 如果用户明确要角色小样、头像、表情或近景风格实验，才允许放大为主体近景。

### 角色-场景画风协同

- 抽象镇小宁涂鸦风是整张图的画风，不是只套在角色身上的滤镜。
- 角色、场景、道具、短词批注和信息载体必须共享同一纸面、同一乱线密度、同一手绘完成度；场景应像孩子或创作者随手画出的桌角、便签、线缆、按钮、纸堆或小工具。
- 轻配图只保留 1 个手绘小局部和 1-3 个抽象道具；中密度可以增加 1-2 个信息区，但仍保持草稿本小剧场；高密度才允许更多材料，但不能变成写实工作台。
- 不要在抽象镇小宁旁边放照片级笔记本电脑、真实数据线、真实便签、摄影棚阴影、产品样机、真实 UI 截图或 stock-photo 桌面。角色是乱线彩铅、场景却是写实照片，判定为画风割裂。
- 如果用户同时要求抽象镇小宁和虚实结合，先说明这是两种不同优先级：默认优先抽象一致性；只有用户明确坚持虚实结合时，才允许极少量真实通用物件，而且必须把物件弱化为纸面拼贴背景，不能压过抽象角色画风。

### 和白底彩铅拉开差异

- 抽象镇小宁必须比白底彩铅版明显更“随手画”和更不稳定：轮廓可以歪、眼睛可以不对称、身体比例可以幼拙，线条要多次往返涂出来。
- 不要把普通镇小宁画得更精致后再加几根乱线；那只是白底彩铅的粗糙版，不是抽象镇小宁。
- 抽象版要优先复用唯一母版的脸型、眼距、红鼻位置、黄色长耳形状、侧耳/侧刺轮廓和蓝色乱线密度；越像干净商业吉祥物，越不合格。
- 如果是多风格对比，抽象涂鸦这张默认少解释、多角色小样感，可以减少道具、短词、箭头和连线，宁可让角色更像草稿本里的抽象小样，也不要为了讲清楚变回普通卡通。

### 和“线团人失败”的区别

- 抽象镇小宁涂鸦风的线条是质感，不是主体类型。
- 线团人是一团线构成的默认主体；抽象镇小宁必须保留镇小宁的外形识别点。
- 如果只剩蓝色乱线、圆眼睛或红鼻子，已经不是合格镇小宁，只能算失败方向预览。

### QA 失败信号

- 把“像真人”理解成真人肖像、拟真人头像、自拍、职业照或半身人像。
- 只剩蓝色身体或圆眼红鼻，其他镇小宁识别点丢失。
- 乱线吞掉五官和轮廓，第一眼认不出镇小宁。
- 变成普通蓝色吉祥物、儿童贴纸、3D 玩具或商业 mascot 海报。
- 镇小宁本体仍是干净普通卡通，只是旁边加了涂鸦云、乱线背景、抽象道具或“AI 味”线团。
- 在正文配图里角色又变成大头主角，抢掉内容现场。
- 角色是乱线彩铅，场景却像写实桌面、摄影棚物件、产品样机或 stock photo，画风不协同。
- 和白底彩铅版差异太小，只是同一个干净角色加了几条乱线，缺少母版的幼拙比例、乱线密度和抽象感。
- 把它当成固定 IP 最终一致性成稿，但没有接入参考图。
- 已有抽象镇小宁唯一母版，却只凭文字重新随机生成，导致耳朵形状、脸型、眼距、肚皮比例或乱线密度和母版明显不一致。

## 实物拼贴手绘风

### 一句话

在白底上用真实物件搭出一个具体工作现场，再让手绘角色在里面完成一个动作：真实物件负责可信度和场景品种，手绘角色负责隐喻、情绪和判断。

### 适合

- Skill 自我介绍、能力展示和 Before/After 价值说明。
- 多风格对比中需要和白底彩铅、抽象涂鸦拉开差异的那一张。
- 工作流复盘、窗口实验日志、项目过程可视化。
- AI 工具、产品功能、协作流程、故障排查和交付链路。
- “虚拟规则如何落到真实工作台”的主题。
- 用户明确喜欢“虚实结合”“实物拼贴”“照片物件 + 手绘小角色”的方向。

### 不适合

- 固定 IP 最终一致性成稿；此风格只能做展示方向或方向预览，正式成稿仍要参考图输入。
- 需要严格角色比例、颜色、线条完全一致的一组 IP 图。
- 文字很多的教程图、密集信息图、正式架构图。
- 极简品牌封面、纯手绘正文配图或需要完全统一画风的系列。

### 视觉材料

- 跟随同组统一白纸底系统：纯白或很浅纸白 / 浅纸色都可以，但不能单独切到浅灰摄影棚、商业摄影棚或另一套底色；真实物件可以有轻微自然影子。
- 通用实物：笔记本电脑、数据线、便签、纸张、回形针、夹子、笔、便签本、旧相框、收纳盒、标签纸。
- 展示、对比或自我介绍图要有更丰富的场景品种，而不是更多物件数量。根据内容自动选择真实材料现场：电脑线缆、打印稿、便签标签、收纳盒、旧相框、工具胶带、样稿堆、笔记本边角、桌面小器具、文件夹边角、夹子和回形针等；同一系列不要总是电脑 + 线缆 + 便签。
- 手绘角色和手写批注叠在真实物件之间，像在现场工作，不像后期贴纸。
- 中文短词仍然少而准，像手写在便签、纸角、云朵批注或物件边缘。
- 不使用真实品牌 logo、真实账号、真实 UI 截图、可识别第三方素材。

### 角色尺度

- 镇小宁或其他固定角色默认是“小操作员”，不是大幅主角。
- 正文配图、通用展示、工作流复盘和方向预览中，角色单体高度通常占画布短边 15%-22%，最高不超过 24%；prompt 必须同时写相对尺度和可读性：角色比真实物件、便签、线缆或纸堆略小或相近，红鼻子、白肚皮、黄耳和大眼清楚，不是远处小贴纸。
- 角色可以靠近真实物件、拉线、贴标签、打结、拖拽、按住、从纸下探出，但不要占据画面中心大块面积。
- 只有角色设定图、封面主视觉、头像、表情或用户明确要求近景时，角色才可以放大到 22%-30%。

### 构图规则

- 真实物件可以比角色大，但不能变成产品广告；物件必须服务一个动作关系。
- 虚实结合也必须遵守信息密度法则：低密度仍只选 1-3 个关键真实物件和 1 个角色动作；中密度使用 4-7 个物件和最多 2 个信息区；高密度才允许更多材料块和分区。不要为了体现真实感增加物件数量。
- Skill 自我介绍、风格对比、能力展示或 Before/After 价值说明中，虚实结合优先更换场景品种，而不是加密画面。例如把“线缆打结”换成“稿纸被压住”“便签从收纳盒露出”“旧相框夹住样稿”“胶带贴住红点”“夹子固定规则卡”“笔记本边角露出批注”等。
- 中密度图可用一个较完整的小桌面现场，但必须有主动作和主阅读路径，不要变成随机桌面摆拍。
- 高密度工作台必须分区明确、有主阅读路径；物件数量由高密度预算决定，不由“虚实结合”单独加码。
- 角色必须参与核心动作；如果去掉角色画面仍完整成立，说明角色只是贴纸，判定失败。

### 颜色和质感

- 真实物件保持低饱和、干净、轻微阴影，不做高级商业摄影光效。
- 手绘角色和批注保留松弛线条、彩铅/铅笔颗粒和不完美边缘。
- 颜色来自真实物件和少量批注色，不做大面积渐变、霓虹光或 3D 吉祥物渲染。

### QA 失败信号

- 真实物件太像商业广告、样机图或 stock photo。
- 自我介绍、能力展示或风格对比里的虚实结合总是同一种电脑、线缆、便签现场，没有根据内容自动更换真实场景品种。
- 手绘角色只是贴纸，没有和物件发生遮挡、拉扯、夹住、压住、露出或修补关系。
- 角色占比过大，抢过真实工作现场和内容关系。
- 角色太小或太边缘，成了装饰而不是动作主体。
- 真实物件虽然多，但没有分组、没有主动作，画面变成随机桌面摆拍。
- 中文太多、太整齐或全是空白标签。
- 固定 IP 最终成稿只靠文字生成，没有接参考图。

## 红笔批改风

### 一句话

像编辑或作者本人拿红笔在 AI 草稿上做批改：圈掉模板句、划掉空话、写下边注，最后留下更像人的表达。

### 适合

- 去 AI 味。
- 反风格清单。
- 标题修改。
- 文案诊断。
- “这句话不像我”的 before/after 对比。
- 把风格 QA 做成一张可视化检查图。

### 不适合

- 温柔陪伴类内容。
- 需要完整世界观或角色动作的插图。
- 产品架构和复杂流程。
- 只想要漂亮配图、不想展示修改痕迹的内容。

### 视觉材料

- 白色稿纸、横线纸或打印稿。
- 黑色或蓝黑色原文。
- 红笔圈、叉、划线、箭头、边注。
- 少量蓝笔补充说明。
- 可以有便签、回形针、夹子，但不要堆满。

### 颜色规则

- 黑/蓝黑：原文和稿纸线。
- 红色：删除、退回、圈重点、边注。
- 蓝色：保留建议或新写法。
- 背景保持干净，不做彩色海报。
- 图片中文字只允许使用 prompt 里列出的短词；这些短词由 Agent 从内容自动提取，默认直接画入，不生成全空白文字容器。

### 线条规则

- 红笔线要有手写抖动和真实批改感。
- 删除线、圈注、箭头可以不完美。
- 边注要短，不写长段话。
- 不要做成整齐 UI 或表格。
- 轻配图只画稿纸碎片，不画完整页面、完整检查清单或长段落。

### 适合的主体

- 红章操作员：适合“退回模板句”。
- 纸片工人：适合“整理修改后的稿纸”。
- 空心方盒：适合“把批改规则归档成 QA”。

### 禁止画法

- 不要满屏红字，保持可读。
- 不要像老师批改小学生作业。
- 不要做成恐吓或审判感。
- 不要伪造真实机构印章。
- 不要生成第三方文章的逐字批改，除非用户有授权。
- 不要自动扩写检查清单、标题或完整段落；只使用允许的短词。
