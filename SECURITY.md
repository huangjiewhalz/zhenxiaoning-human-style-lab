# Security Policy

This repository is a Codex Skill and documentation project. It should not contain production secrets, API keys, private chat logs, or personal account credentials.

## Supported Versions

The `main` branch is the maintained branch.

## Reporting a Security Issue

If you find a security issue, open a GitHub issue with minimal reproduction details and avoid posting secrets or private data. If the issue includes sensitive material, describe the category of the issue and redact the sensitive values.

## Data and Privacy Expectations

- Do not commit API keys, access tokens, cookies, `.env` files, private chat exports, or unpublished user materials.
- Do not include user-uploaded IP assets unless the user owns them or has explicit authorization.
- Do not include third-party copyrighted characters, celebrity likenesses, or living creator style samples as reusable references.
- Window experiment logs should summarize process nodes, not expose full private conversations.

## Model and Tool Safety

This Skill may ask an agent to read local references, plan visual outputs, or generate prompts. It should not ask the model to:

- bypass AI detectors,
- impersonate another person,
- clone an identifiable living creator style,
- retrieve private data from unrelated local paths,
- publish user assets without authorization.
