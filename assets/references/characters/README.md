# Character References

固定 IP 主体参考图放在这里，用于让连续配图保持同一个角色。

## Built-In Reference

- `zhenxiaoning-reference.png`：镇小宁固定参考图。用户点名“镇小宁 / zhenxiaoning”时优先读取这张图；如果当前模型/环境不能看图，再使用文字识别点：蓝色圆润身体、黄色触角、红鼻子、大白眼、白肚皮、短手短脚。

## User-Owned IP

用户要长期使用自己的 IP 时，把授权角色图放到这里，推荐命名：

```text
<subject-slug>-reference.png
```

短期测试可以直接在对话里上传角色图，不必改文件。长期复用时，再把图片放进本目录，并生成或更新 `references/ip-subject.md`。

`ip-subject.md` 必须写清：

- 参考图路径。
- 来源授权：用户原创 / 用户授权品牌资料 / 待确认。
- 识别点：颜色、体型、五官、标志部件、比例、表情气质。
- 禁改点。
- 动作库和常见道具。
- 连续配图只能使用同一个主视觉主体。

不要放入第三方 IP、名人形象、在世创作者可识别角色、未授权品牌角色，也不要把第三方角色改色当作用户自己的 IP。
