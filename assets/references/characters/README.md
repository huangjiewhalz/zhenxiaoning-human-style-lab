# Character References

固定 IP 主体参考图放在这里，用于让连续配图保持同一个角色。

## User-Owned IP

用户要长期使用自己的 IP 时，把授权角色图放到这里，推荐命名：

```text
<subject-slug>-reference.png
```

短期测试可以直接在对话里上传角色图，不必改文件。长期复用时，再把图片放进本目录，并生成或更新 `references/ip-subject.md`。

如果创作者只想在自己本机默认使用某个私有 IP，不想公开到 GitHub，可以使用 `references/ip-subject.local.md` 绑定本机私有参考图。这个文件应该被 `.gitignore` 忽略，不进入公开仓库。

优先级规则：

- 当前对话上传的角色图永远优先于本目录里的任何旧参考图。
- 本机私有 `references/ip-subject.local.md` 明确允许默认使用时，优先于公开固定目录。
- 本目录不是自动候选池；不要因为这里有图片就默认使用。
- 只有用户明确指定某个文件路径，或 `references/ip-subject.local.md` / `references/ip-subject.md` 明确绑定当前角色和该文件路径，才读取这里的图片。
- 如果本目录里的图片和用户当前上传/点名的角色不一致，忽略本目录图片并使用用户当前提供的角色。
- 如果用户点名了具体角色但本目录没有对应绑定参考图，也没有当前上传图，不要使用默认主体代替该角色；先要求用户上传或指定参考图。

`ip-subject.md` 或 `ip-subject.local.md` 必须写清：

- 参考图路径。
- 来源授权：用户原创 / 用户授权品牌资料 / 待确认。
- 识别点：颜色、体型、五官、标志部件、比例、表情气质。
- 禁改点。
- 动作库和常见道具。
- 连续配图只能使用同一个主视觉主体。

不要放入第三方 IP、名人形象、在世创作者可识别角色、未授权品牌角色，也不要把第三方角色改色当作用户自己的 IP。
