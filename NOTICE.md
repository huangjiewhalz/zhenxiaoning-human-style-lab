# Notice

Zhenxiaoning Human Style Lab is an open source Codex Skill project for personal style assets, anti-AI-flavor writing workflows, visual IP consistency, and hand-drawn content illustration planning.

## Character Assets

This repository does not publish a built-in fixed IP reference for reuse. If you fork this project to build your own personal style Skill, add your own original or authorized IP asset:

```text
assets/references/characters/<subject-slug>-reference.png
```

Do not use third-party IP, public creator characters, celebrity likenesses, or unauthorized brand characters as your fixed subject.

## Third-Party Style Boundary

This project does not provide instructions for cloning a living artist, creator, blogger, brand, or third-party character style. It only supports:

- user-owned work,
- user-authorized brand or project material,
- abstract visual or writing directions,
- original or authorized IP references.
