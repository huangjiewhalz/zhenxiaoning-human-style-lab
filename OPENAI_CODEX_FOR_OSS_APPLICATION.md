## Short Project Description

```text
Zhenxiaoning Human Style Lab is an early open source Codex Skill for turning a creator's own writing samples, visual preferences, fixed IP character, anti-style rules, and platform image requirements into reusable personal style assets.
```

## Why This Repository Fits

```text
This is an early but actively maintained open source Codex Skill project. It addresses a practical creator workflow: reducing generic AI flavor by turning personal style evidence, anti-style constraints, visual subject consistency, hand-drawn metaphor planning, and platform-specific image sizing into reusable Skill references.

The repository contributes a concrete example to the Codex Skills ecosystem: a Chinese creator-focused personal style asset workflow rather than a generic prompt pack. It includes structured references, QA rules, compliance boundaries, fixed visual subject guidance, showcase examples, and maintenance documentation.

The project is honest about its current stage: it is an early public repository, not yet a widely adopted project. The goal is to keep improving it through real creator use cases, issue-driven QA, and repeatable examples.
```

## How API Credits Would Be Used

```text
API credits would be used to maintain and test this open source Skill:

- generate cross-model test cases for writing, title, script, and visual prompt workflows;
- validate whether outputs preserve personal style evidence instead of drifting into generic AI tone;
- test fixed visual subject consistency across multi-image series;
- test platform sizing prompts for X, WeChat, Xiaohongshu, Instagram, and vertical video formats;
- build regression examples for low, medium, and high density visual layouts;
- review pull requests and issues with Codex-assisted checks;
- improve README, reference files, examples, and QA checklists;
- experiment with lightweight evaluation scripts that detect common failure signals such as subject swapping, over-dense layouts, and third-party style imitation risk.
```

## What Makes It Useful for OSS

```text
The project can help other builders understand how to package taste, constraints, examples, failure signals, and model limitations into a reusable Skill. It also documents boundaries that matter for open source AI tooling: only use user-owned or authorized style assets, avoid imitating living creators, and make visual subject references explicit instead of relying on vague prompts.
```

## Current Limitations

```text
The repository is still early. It currently has a small public footprint and is being improved through hands-on testing. The next useful work is to add more reproducible examples, issue templates, lightweight validation scripts, and community feedback loops.
```

## Extra Note

```text
The project grew from the Zhenxiaoning AI experiment, but the workflow is designed for other creators too. Users can replace the built-in Zhenxiaoning reference with their own authorized IP asset and generate their own personal style Skill pack.
```
